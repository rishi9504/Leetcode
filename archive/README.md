# Archive

This directory preserves superseded Phase 1 material for history and recovery.

- `legacy-solutions/` contains standalone solutions whose executable approach is already represented by a canonical synced folder.
- `legacy-docs/` contains the former manual problem list and general roadmap, now replaced by generated revision navigation.
- `notes/` contains earlier free-form pattern notes whose useful ideas were folded into the revision dashboard and pattern pages.

The three genuinely distinct legacy implementations were preserved under their canonical problem folders in `alternatives/` instead of being archived here.
