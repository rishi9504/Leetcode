# Tree DFS / Recursion

[Pattern index](README.md) | [Revision dashboard](../README.md)

## Recognition Signals

Subtree answers combine at a node or path state flows from root to leaf.

## Mental Model

Define what each recursive call returns, then combine child results once.

## Variants

- DFS
- Depth and Parent Tracking
- Depth-Indexed Aggregation
- Heap-Style Position Indexing
- Leaf Sequence Comparison
- Lockstep Tree Comparison
- One-Child-Aware Minimum Depth
- Path Maximum
- Postorder Height Sentinel
- Postorder Heights Update the Diameter
- Recursive Pairwise Merge
- Tree Postorder / Return Information
- Tree Traversal
