# Linked List Techniques

[Pattern index](README.md) | [Revision dashboard](../README.md)

## Recognition Signals

Pointer rewiring, relative node positions, or cycle structure.

## Mental Model

Name pointer roles and update links without losing access to the remaining list.

## Variants

- Dummy-Head Sorted Merge
- Fast & Slow Pointers
- Fast and Slow Pointer Gap
- Fast and Slow Pointers with Predecessor
- Linked List Reversal
- Linked List Traversal
- Odd/Even Position Chains
- Recursive Pair Reversal
- Reverse the Second Half
- Single-Pass Link Skipping
